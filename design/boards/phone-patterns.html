Board 79 · Managing patterns: a Patterns sheet, clearing, and reuse when the pool is full

Decision 38. iPhone 17 Pro landscape, 874 × 402 pt at 1:1; the Pixel is the same layout. The pool is the FM-1’s 64 pattern numbers, shared by every saved project. The sheet opens from the song-name menu (“Patterns…”), from the full-pool notice, and from an empty slot’s hold menu when the pool is full. It lists kept patterns only (empty numbers are just the free count); white because the pool is global, each pattern’s uses tagged with their tracks’ colours.

How it works (from P1’s read of the protocol)

  • Always live, even playing: each number’s length, whether it’s kept, how many things use it, which pads of this project use it (“T2 A · T4 C”), and a dot when saved projects use it too.
  • Only while stopped: the thumbnails (the FM-1’s stored notes, read once when the sheet opens and cached, re-read only for patterns that changed) and which saved project holds a pattern. Reading them stops playback the first time, so while playing the sheet shows length bars and says “Stop to load pictures”.
  • Clear only patterns nothing uses (dashed cards); used ones can’t be picked, and tapping one says where it’s used. One confirm in place, red only on the confirm key; can’t be undone; stopped only. Clear all unused is the same with every dashed card picked.
  • Reuse when full (75.4): the empty slot’s menu offers Recycle an unused pattern (puts an unused number on the pad, then empties it: a fresh pattern without a free number; stopped only) and Put a kept pattern here… (opens the sheet to pick one; the pad then plays the same pattern as its other users, edits shared). “Copy a pattern” needs a free number, so it’s offered only when one is.
  • Not possible on Skiff: names, renumbering, choosing the number a new pattern gets, or which scene uses a pattern (scenes never hold one).
