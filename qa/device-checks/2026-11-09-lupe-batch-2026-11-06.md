# Device check: lupe-batch-2026-11-06, 2026-11-09

The first one. It covers the 90 commits on `lupe-batch-2026-11-06` that `main` doesn't have (11-06 to 11-08), plus the device checks still owed from 11-06. It was written after the fact from the commits, the QA notes and the batch list, so it's longer than a normal one. Expect about 30 minutes. Do part A first: it's the only part that writes the FM-1's flash.

**Setup:** the FM-1 on Skiff with Lupe's screen link (whatever build it has now; check 1 updates it) · Lupe from `lupe-batch-2026-11-06` at 2a8ef5f or later, installed from Blue Lion · USB cable to the FM-1, headphones in the FM-1.
**Back up first?** Yes, for checks 1–4. Save the project in Lupe (Projects) and keep the current firmware package to hand.
